# Модель распознавания зацепок

Для обычной работы приложения обучение не требуется: сайт использует готовую YOLOv8n FreeClimbs из Hugging Face. Ноутбуки ниже — отдельные эксперименты с RF-DETR и RTMDet; их веса не подключены к сайту.

Модель выполняется в браузере через ONNX Runtime Web. Фото остаётся на устройстве пользователя; сервер распознавания и платный API не используются. После обнаружения моделью приложение также ищет пиксели выбранного цвета по всей фотографии, чтобы найти пропущенные зацепки, и показывает контуры для проверки.

## Бесплатное обучение

1. Откройте [`train_climbing_holds.ipynb`](train_climbing_holds.ipynb) и загрузите его в Kaggle Notebooks.
2. В настройках ноутбука включите Internet и бесплатный GPU (T4 или P100, если доступен).
3. Создайте бесплатный API key на Roboflow Universe. Ноутбук запросит его через скрытый ввод, ключ не сохраняется в исходнике.
4. Запустите ячейки по порядку. Ноутбук установит зависимости для обучения и экспорта, скачает набор Climbing Hold Detection v26, дообучит RF-DETR Seg Nano и создаст компактную INT8 ONNX-модель.
5. Скачайте `climbing-holds-int8.onnx` из результата Kaggle, если хотите отдельно проверить или интегрировать обученную модель.
6. Обычный сайт не использует этот файл: он продолжает работать на предобученной YOLOv8n без Kaggle и Roboflow.

> Бесплатный GPU в Kaggle зависит от доступности и квоты аккаунта. Если GPU временно недоступен, ноутбук можно запустить позже. Во время обычной работы сайта Kaggle и Roboflow не нужны.

## Проверить альтернативу RTMDet-Ins-Tiny

Для отдельного сравнения есть [`train_rtmdet_ins_tiny.ipynb`](train_rtmdet_ins_tiny.ipynb). Он использует тот же набор COCO и обучает RTMDet-Ins-Tiny на одном GPU. Чтобы не собирать несовместимые CUDA-расширения под Python 3.13 из Kaggle, ноутбук создаёт отдельное окружение Python 3.10 с готовым MMCV wheel. Сначала запускается короткий smoke-прогон на подмножестве данных, затем — обучение на полном наборе.

Результат этого ноутбука — PyTorch checkpoint `.pth` и метрики сегментации. Это эксперимент для сравнения; приложение Skalyk продолжает использовать предобученную YOLOv8n.

## Что умеет модель и где нужна проверка

- Набор содержит контурные метки двух классов: `hold` и `volume`. Модель ищет оба типа элементов.
- Эксперименты RF-DETR/RTMDet обучаются находить зацепки и объёмы по набору с контурными метками. Текущая веб-модель YOLOv8n выдаёт прямоугольники, а контуры выбранного цвета строятся в браузере отдельным анализом фотографии.
- В исходных данных нет меток стартов и финишей. Приложение предлагает нижнюю и верхнюю отметки по высоте стены, а пользователь должен проверить или исправить их.
- Пользователь проверяет контуры, может удалить лишние или добавить пропущенные отметки вручную.
